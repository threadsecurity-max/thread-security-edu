# Course and Academy Shared Documents

Welcome! This folder is a dedicated space for sharing course descriptions, syllabus files, PDF guides, and documentations about Thread Security Academy courses.

## How to use this folder:
1. **Drop any course-related documents here**: You can add `.pdf`, `.txt`, `.md`, `.json`, or `.csv` files containing details about course modules, pricing, mentorship schedules, and academy structures.
2. **Tell me when you add new files**: Whenever you drop a new document or PDF in this folder, just let me know (e.g., *"I have added the syllabus for Cloud Security to the shared folder, please read it"*). I can read the contents of standard text files as well as PDF documents directly.
3. **Ask questions about the materials**: Once the files are here, I can retrieve definitions, module breakdowns, or policy guidelines from them to update pages, generate course details, or answer queries.

### Supported Formats:
- **PDF (.pdf)**: Best for official curriculum syllabi and course outlines.
- **Markdown (.md) / Text (.txt)**: Best for structured notes, outlines, and descriptions.
- **JSON (.json) / CSV (.csv)**: Best for structured data sheets like course prices, lists, and schedules.
